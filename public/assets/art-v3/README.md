20 новых оригинальных изображений. Каждое создано отдельным вызовом встроенного `image_gen`, не CLI и не сборкой из SVG. Оригинальные PNG сохранены; старые файлы логотипа не заменялись.

Галерея в локальном приложении: http://127.0.0.1:3000/art-gallery.html

Исходники: 1254×1254 PNG; главный баннер — 1536×1024 PNG. Для интерфейса созданы WebP по 360 и 720 px, главный баннер — 1440 px. Вся серия из 20 маленьких WebP занимает примерно 200 КБ, а все производные файлы — менее 1 МБ. Размеры и наличие файлов проверяются автоматически.

Пересборка сжатых копий: `npm run assets:build`. Sharp выполняет только масштабирование/сжатие; PNG не редактируются. Тексты и цены остаются настоящими элементами интерфейса, а не частью картинок.
