# Шрифты визуальных карточек

PT Sans Regular / Bold и PT Serif Regular / Italic, ParaType.

Оригинальные неизменённые TTF получены из официального репозитория Google Fonts:

- https://github.com/google/fonts/tree/main/ofl/ptsans
- https://github.com/google/fonts/tree/main/ofl/ptserif

SIL Open Font License включены в PT-Sans-OFL.txt и PT-Serif-OFL.txt. Шрифты используются в SVG-предпросмотре и при серверном рендере JPEG, чтобы кириллица отображалась независимо от системных шрифтов хостинга.
