# Подключение «Очевидно» к Telegram и Railway

## 1. Публичный адрес — не ссылка на настройки Railway

Откройте сервис приложения в Railway → Settings → Networking → Public Networking → Generate Domain. При PORT=3000 целевой порт домена тоже 3000. Скопируйте адрес `https://…up.railway.app`.

В Variables сервиса приложения задайте `PUBLIC_APP_URL` равным этому адресу, без пути и параметров. Альтернатива — `https://${{RAILWAY_PUBLIC_DOMAIN}}`. Если переменная PUBLIC_APP_URL отсутствует, сервер сам использует RAILWAY_PUBLIC_DOMAIN; явно заданный неправильный адрес он не подменяет молча.

`https://railway.com/project/…`, ссылка на репозиторий GitHub и localhost здесь не подходят.

## 2. Переменные сервиса приложения

```dotenv
NODE_ENV=production
PORT=3000
ALLOW_DEMO=0
PUBLIC_APP_URL=https://ВАШ-ДОМЕН.up.railway.app
BOT_TOKEN=НОВЫЙ_ТОКЕН_ОТ_BOTFATHER
ADMIN_TELEGRAM_IDS=ВАШ_ЧИСЛОВОЙ_TELEGRAM_ID
DATABASE_URL=${{Postgres.DATABASE_URL}}
SUPPORT_URL=https://t.me/ЛОГИН_МЕНЕДЖЕРА
```

Имя `Postgres` в ссылке должно совпадать с именем вашего сервиса базы. Не публикуйте токен и строку подключения в GitHub, скриншотах и чате. Если настоящий .env когда-либо загрузили в репозиторий, перевыпустите токен и все другие попавшие туда секреты: удаление файла не удаляет старые коммиты.

Root Directory: `/`, если package.json и src лежат в корне репозитория. Start Command: `npm start`. Один процесс запускает и веб-сервер мини-аппа, и Telegram polling. Не запускайте вторую копию с тем же токеном, оставьте одну реплику. Локальный `npm run demo` изолирован от настоящего бота и базы.

Если адрес мини-аппа отсутствует или указан неверно, бот не падает: приветствие, справка и поддержка работают, а новые покупки заблокированы до настройки адреса. Владелец получает проблему в админке. Это не разрешает демо-оплаты в production и не ослабляет проверку Telegram-подписи.

## 3. Деплой и проверка адреса

Закоммитьте код и выполните `git push`. Если сервис подключён к этой ветке и автодеплой включён, Railway соберёт новую версию. В ином случае запустите деплой последнего коммита в Railway.

После запуска откройте `https://ВАШ-ДОМЕН.up.railway.app/health`: ожидается `{"ok":true,"mode":"telegram"}`. Ответ 502 обычно означает, что процесс не запущен или порт домена не совпадает с PORT; смотрите Deploy Logs.

Обычный переход на главную в браузере не даёт авторизации Telegram. Страница предложит перейти в бота. Не включайте ALLOW_DEMO в продакшене ради обхода авторизации.

## 4. Кнопки Telegram

Напишите своему боту `/start`. Приветствие покажет зелёную inline-кнопку «Открыть „Очевидно“» и нейтральные дополнительные кнопки. Цвет inline-кнопки задаётся полем style=success и виден в поддерживающих его версиях Telegram. Кнопка возле поля ввода использует оформление клиента Telegram, её цвет API не задаёт.

Кнопка возле поля ввода настраивается кодом через setChatMenuButton. Чтобы приложение также открывалось из профиля и ссылок `?startapp=…`, выберите своего бота у @BotFather и настройте Main Mini App на тот же публичный HTTPS-адрес. Названия подразделов интерфейса BotFather могут отличаться между версиями.

Если когда-то задавали индивидуальную кнопку меню этому чату вручную, она может перекрывать общую. `/status` показывает фактическую кнопку текущего чата и ожидаемый адрес. Нажмите «Восстановить кнопку меню» — бот обновит её для вашего чата. Эта операция доступна только владельцу и не заменяет настройку Main Mini App у BotFather.

## 5. Оформление

Приветствие, длинное описание перед первым стартом, короткое описание профиля и подпись основной кнопки меняются в мини-аппе: профиль → Админ-панель → Бот. Собственные тексты сохраняются при обновлениях; старые неизменённые стандартные тексты заменяются новыми автоматически.

При запуске сервер устанавливает `public/assets/avatars/bot-avatar-v2.jpg` через Telegram setMyProfilePhoto. Хеш успешной установки хранится в базе; тот же файл при следующем запуске не загружается повторно. При ошибке бот продолжит работать, а владельцу появится проблема в админке. Запасной вариант: @BotFather → `/setuserpic` → выбрать бота → отправить эту JPG-картинку.

Аватарку менеджера `public/assets/avatars/manager-avatar-v2.jpg` установите вручную в профиле Telegram-аккаунта менеджера. Код бота не имеет доступа к личному аккаунту. Укажите его username в SUPPORT_URL. Для отдельного менеджер-бота можно использовать `/setuserpic` у BotFather.

Исходники и точные промпты: `public/assets/avatars/prompts-v2.md`. Аватарки сгенерированы встроенным imagegen, JPG/WebP подготовлены скриптом `npm run avatars:build`. Старые изображения сохранены локально в `artifacts/brand-v1`, этот архив не включён в деплой.

В админке → Бот показаны обе аватарки с кнопками скачивания JPG и список проверок подключения. Кнопка повторной проверки не сбрасывает несохранённые тексты формы. Проверки отражают настройки и последнюю успешную синхронизацию, не выполняют внешний мониторинг и не заменяют проверку реального платежа.

Изображения уже включены в Git, на Railway их не нужно генерировать. JPG/WebP с версионными именами и оптимизированные обложки art-v3 в production отдаются с годовым кэшем (`immutable`), HTML всегда перепроверяется. Для новой картинки используйте новую версию имени: старые кэшированные файлы не мешают обновлению. Длительное хранение не требует временного файлового хостинга; файлы находятся в репозитории и в образе деплоя. Не меняйте содержимое уже опубликованных versioned-файлов без увеличения версии.

## 6. Проверка перед приглашением покупателей

1. `/start`: имя, приветствие, зелёная кнопка; карточки и картинки открываются внутри Telegram.
2. `/help`, `/about`, `/terms`: понятные тексты и действующие кнопки.
3. `/paysupport`: описание следующим сообщением создаёт обращение с номером. `/cancel` отменяет ввод. Пароли и seed-фразы поддержка не запрашивает.
4. `/promo КОД`: созданный владельцем тестовый промокод активируется один раз.
5. Владелец: `/admin` открывает путь к админке, `/status` показывает настройки без токена и строки базы. Обычный пользователь не получает эти сведения.
6. Купите одну недорогую карточку в настоящих Stars. До successful_payment результат закрыт; после оплаты он доступен в коллекции и после повторного входа. Отмена оплаты не выдаёт результат.
7. Оформите тестовый возврат в админке, проверьте статистику и поддержку. Реальные списания/возвраты проверяйте отдельно; локальные тесты не подтверждают работу внешней платёжной системы.
8. `/stop` выключает рекламные сообщения, но не покупки и поддержку.

## 7. Бесплатные открытия для себя или другого пользователя

1. Напишите боту `/admin` и откройте админ-панель → **Бесплатные открытия**.
2. Для себя нажмите **Выбрать мой профиль**. Для другого человека введите числовой Telegram ID или `@username` и нажмите **Найти пользователя**. Он должен хотя бы раз нажать `/start` или открыть мини-апп. Username ищется по сохранённым данным; надёжнее ID. При совпадении старых username потребуется ID.
3. Проверьте имя и Telegram ID получателя. Укажите, например, 10 открытий и необязательный комментарий. Нажмите **Выдать бесплатные открытия**. За один раз можно выдать 1–1000; выдачи сохраняются в истории и журнале администратора.
4. Пользователь заново открывает мини-апп. В профиле появится остаток. В любой доступной карточке выберите **Бесплатное открытие**, заполните поля, примите правила и нажмите **Открыть бесплатно**. Если попытки есть, этот способ выбран по умолчанию.
5. Одна попытка открывает одну карточку или целый набор, включая дорогие. Повторный просмотр в коллекции бесплатен. Нельзя вывести или передать эти попытки. Stars и бонусы не списываются, выручка не увеличивается; в отчётах есть отдельный счётчик. Пауза продаж и скрытие карточек действуют и на бесплатные открытия.

База обновляется автоматически при запуске, без новых переменных окружения и без удаления старых данных. Бесплатный доступ проверяет карточки и документы, но не заменяет проверку настоящей оплаты Stars и возврата.

## 8. Как сохранить грамоту

В коллекции откройте грамоту → **Скачать грамоту · SVG**. В поддерживающем загрузку клиенте Telegram появится системное подтверждение. В обычном браузере файл отдаётся как вложение; проверьте папку загрузок. SVG — векторная картинка, её можно открыть браузером или графическим редактором.

Запасной вариант — **Получить файлом в боте**: бот отправляет SVG-документ в личный чат владельца покупки. Сохраните вложение из этого сообщения. Если бот не может отправить сообщение, сначала откройте с ним личный чат, нажмите `/start` и разблокируйте его. В демо отправка отключена; браузерное скачивание доступно.

Для набора сначала откройте конкретную грамоту внутри набора. Каждый документ скачивается отдельно. Короткая ссылка на файл выдаётся авторизованному владельцу, действует 5 минут и не требует передачи Telegram-подписи загрузчику. Не пересылайте такую ссылку, если не хотите делиться своим документом; после истечения срока создайте её снова кнопкой скачивания. Если доступ к покупке отозван после возврата, старая ссылка перестаёт работать.

Gram — название монеты; TON — название блокчейна. Профиль показывает открытый баланс Gram из подключённого кошелька. Подключение не начисляет монеты, не создаёт депозит внутри приложения и не даёт приложению права списывать средства. Цифровые карточки продаются в Stars, без оплаты криптовалютой: https://core.telegram.org/bots/payments-stars.
